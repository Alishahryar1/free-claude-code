`rtk-opencode-v1.ts` is the unchanged RTK 0.44.2 OpenCode plugin template from
[rtk-ai/rtk](https://github.com/rtk-ai/rtk/blob/v0.44.2/hooks/opencode/rtk.ts).
It is covered by the accompanying [Apache 2.0 license](rtk-LICENSE).

The fixture preserves the exact bytes emitted by RTK so installer tests verify
that only the recognized generated plugin is disabled. Keep its LF line endings.
