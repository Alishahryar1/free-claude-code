# Provider logo sources

Logos identify the services linked by the provider cards. Brand marks belong to their respective owners.

SVGs from Lobe Icons 1.95.0 are distributed under the included MIT license. SVGs using currentColor set a light foreground for the dark Admin UI; colored paths are preserved.
The LLaMA.cpp icon comes from the upstream llama.cpp repository; its MIT license is included. Other images are the providers' published site icons, copied without modification.
